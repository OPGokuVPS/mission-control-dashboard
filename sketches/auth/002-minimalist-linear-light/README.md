## Variant 002 — Minimalist Linear Light

### Design stance
Clean, light-on-white aesthetic inspired by Linear/Vercel — minimal chrome, generous whitespace, top-aligned social auth as the primary action.

### Key choices
- Layout: single-column, narrow max-width (~400px) centered
- Typography: Inter, small weights, uppercase tracking for labels
- Color: white bg, slate text, indigo accent on interactive elements only
- Auth order: social buttons FIRST, email below "or" divider — signals OAuth as preferred flow
- Inputs: underline-only style (no box borders), focus highlights bottom border in indigo
- Subtle dot pattern bg adds depth without distraction

### Trade-offs
- Strong at: fast scanning, professional feel, feels "production-ready"
- Weak at: less brand impact than split-screen, can feel too generic

### Best for
- Enterprise/internal tools where users value clarity over spectacle
- Users who want quick login without being sold a pitch
